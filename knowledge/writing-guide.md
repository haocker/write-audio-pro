# 写乐谱指南（write_audio_pro）

引擎只管渲染；这支曲子好不好听，全看你写的乐谱。本文是方法与套路。

---

## 1. 时间模型

- 一切以**拍（beat）**为单位。`bpm=66` → 1 拍 = 60/66 = 0.909 秒；一小节（4 拍）= 3.64 秒。
- 第 n 小节（1 基）内第 b 拍的绝对拍位置 = `s.bar_to_beat(n, b)`。
- 时长控制：`s.length(bars=48)` → 输出 = 48 × 小节秒数 + `tail`。
- 不设 length 时：自动取"最后一个音符的结束拍"。

```python
B = song.bar_to_beat          # 简写，后面到处用
piano.note(B(5, 2.0), "E5", 1.0)   # 第 5 小节第 2 拍
```

## 2. 音符写法

```python
t = song.track("piano")
t.note(0, "A4", 2.0, 74)          # (at拍, 音名/MIDI, 时值拍, 力度0-127)
t.notes([(0,"A4",2), (2,"C5",2), (4,57,1)])          # 批量
t.notes([{"at":4, "pitch":57, "dur":1, "vel":0.6}])  # dict；vel 可 0.0-1.0 比例
t.chord_at(0, "Am7", dur=4, octave=3)                 # 和弦名直达
t.pad_chord(1, "Am", dur=4)                           # 按小节落和弦垫
```

- `pitch`：音名（`"A4"` `"F#2"` `"Bb"`）或 MIDI 数值。
- **write_audio_pro 无打击乐**：每个音符都必须有音高。
- 力度 `vel`：0-127 整数，或 0.0-1.0 比例（自动 ×127）。用作表情——不要全用同一个值。

## 3. 乐理工具

```python
wa.midi("A3")            # 57
wa.chord("Am7", 3)       # [57, 60, 64, 67]；支持 C/E、F#m7b5、G7sus4、add9…
wa.chord("C/E", 3)       # 斜杠低音：E 在低音位
wa.scale("A", "minor", 3)  # [57,59,60,62,64,65,67,69]
wa.note_name(57)         # "A3"
```

- 写旋律时用 `wa.scale()` 的索引运算（`sc[2]+12` 等）构造音高。
- 写和声垫时直接 `wa.chord(和弦名, 八度)`。

## 4. 配器与编曲（各声部怎么写）

抒情音乐最实用的编制（也见 `wa.ENSEMBLES`）：

| 编制 | 乐器 | 用途 |
|---|---|---|
| 钢琴独奏 | `piano` | 主题、内心独白 |
| 钢琴三重奏 | `piano` + `violin` + `cello` | 室内乐，亲密 |
| 悲伤电影感 | `piano` + `strings` + `cello` (+`choir`) | 情感张力 |
| 管弦 | `strings` + `brass` + `flute` + `timpani` | 宏大 |

### 4.1 钢琴（piano）——主奏
- 右手唱旋律，左手铺织体。
- 左手常用：根音长音、分解和弦（根-五-根-十）、宽广琶音。
- 力度要有起伏：主题 74-84，高潮 88-95，尾声 60-70。

### 4.2 弦乐（strings）——和声垫
- **每小节一个和弦**，与和声进行逐小节对齐（别让长音跨越和弦变化）。
- `pad_chord(bar, 名称, dur=4)` 已自动加低八度根音，更饱满。
- 不同段落换八度：独白低八度（`octave=2`）当 soundbed，主段中八度（`octave=3`），高潮高八度（`octave=4`）。
- 力度：独白 30-40，主段 46-58，高潮 70-76。

### 4.3 大提琴（cello）——低音线条
- 每小节一个长音，走和弦根音（低八度）：`cello.note(B(bar,0), 根音, 3.8, 58)`。
- 让低音有走向（级进上行/下行），比一成不变更有张力。

### 4.4 合唱（choir）——高潮叠色
- 只在最高潮用，高八度叠和弦音，力度小（30-38），增加神圣/悲怆感。
- 用多了会糊，点到为止。

## 5. 结构与情绪骨架

悲伤抒情曲可以直接照抄这个骨架改（48 小节 @63bpm ≈ 3:00）：

| 段落 | 小节 | 内容 | 力度 |
|---|---|---|---|
| 独白 | 8 | 钢琴单音 + 极轻弦乐 | 弱 |
| 倾诉 | 12 | 主题浮出 + 大提琴 + 左手分解 | 中 |
| 翻涌 | 12 | 旋律移高八度 + 八分流动 | 中强 |
| 释放 | 8 | 全编制 + 合唱 + 宽广琶音 | 最强 |
| 归寂 | 8 | 层层退出 → 单音落定 → 渐弱 | 渐弱到无 |

情绪推进三大手段：**加层**（乐器数量）、**加密**（音符密度）、**抬高**（八度/音区）。

## 6. 混音与母带

### 6.1 音量控制（重中之重：避免乐器互相盖过）

引擎提供三层音量手段，**全部由你在乐谱里显式控制**（没有黑箱自动平衡）：

```python
# ① 分轨基准音量——整曲电平，先定大局
song.mix(piano=0, strings=-7, cello=-5, choir=-11)
song.balance(lead="piano", others_db=-9)         # 主奏 0dB、其余统一 -9dB

# ② 段落级音量包络——跟随情绪写曲线（最常用）
song.set_volume("strings", 1, -20)     # 独白：弦乐几乎只是气声
song.set_volume("strings", 33, -5)     # 高潮：最饱满
song.set_volume("cello", 45, -60)      # 尾声：大提琴退场（-60dB≈静音）

# ③ 同轨内力度（velocity）——表情起伏
piano.notes([(0, "A4", 2, 74), (2, "C5", 2, 82)])
```

**平衡原则**（抒情编制 piano + strings + cello）：

| 声部 | 基准音量 | 说明 |
|---|---|---|
| 主奏（piano） | 0 dB | 始终最清晰，是"主角" |
| 和声垫（strings） | -6 ~ -8 dB | 托住但不抢 |
| 低音（cello） | -4 ~ -6 dB | 低音略高不易被掩蔽 |
| 叠色（choir） | -10 ~ -12 dB | 只在高潮，点到为止 |

- **段落音量包络**比固定音量重要得多：独白时的弦乐要 -18~-22dB，高潮时 -5dB——
  同一件乐器在不同段落"让位/托起"，才是好的编配。
- 相邻音量点之间按 **dB 线性过渡**；首点前/末点后保持。`set_volume(0, -60)` 可实现"从静音渐入"。
- **诊断**：渲染后看 `rep["tracks"]` 的 `rms_db`——各声部混音后 RMS 差最好在 **8dB 以内**；
  若差距过大，`rep["warnings"]` 会提示。据此微调 `mix` / `set_volume`。

### 6.2 空间与母带

- **混响**：`render(reverb_mix=0.30, reverb_room=0.62)`。抒情曲 0.25-0.35，室内乐 0.15-0.25。
- **声像**：pad/strings 稍左（`pan=-0.15`），choir/bell 稍右（`pan=0.2`），钢琴/大提琴居中。
- **母带自动完成**：预归一 → 响度 → 软限幅（峰值 ≤0.94）→ 复测。
  稀疏、长静音的抒情曲其自然 LUFS 本就低于 -14，引擎会**保护动态**不强压——
  这是对的，硬压到 -14 会毁掉情绪。

## 7. 结尾安全做法

不要在已渐弱的尾声上让伴奏突现，也不要放重击。正确做法：

1. 逐层退出：先停大提琴 → 弦乐降八度变轻 → 钢琴收；
2. 最后 1-2 小节只留钢琴（+一个长音）；
3. `s.fade(out_seconds=5.0)` 渐出到真正静音；
4. 验证：渲染后看最后 5 秒的 0.5s 窗口 RMS 曲线，应单调下降。

## 8. 常见坑

- **乐器互相盖过**：先看 `rep["tracks"]` 的 `rms_db`，差距 >8dB 就调 `mix` / `set_volume`。
  段落音量包络（`song.set_volume("strings", bar, db)`）比整轨固定音量更有效。
- **曲长**：最后一小节的长音 dur 会撑长曲长（不设 length 时）。设了 `s.length(bars=)` 后，音符不超出即可。
- **和弦错位**：pad/strings 时长别跨越和弦变化，否则盖错和弦。
- **`pad_chord` 的 bar 是 1 基**：第 1 小节就是 `bar=1`。
- **缺音高报错**：write_audio_pro 无打击乐，每个 `note` 都要给音高。
- **SoundFont 找不到**：设 `WRITE_AUDIO_PRO_SF2` 环境变量，或检查 `wa.find_soundfont()`。
- **确定性**：不要用 `random`——所有"变化"都写成显式音符/循环/音量点。

## 9. 从零写一支曲子的流程

1. `s = wa.Song(bpm=...)` + `s.length(bars=...)` 定规格；
2. 和弦循环 `PROG` + 根音表；
3. 逐段落编排：先钢琴骨架 → 弦乐垫 → 大提琴 → 高潮叠色；
4. `--check` 看摘要（各声部音符数是否合理）；
5. 渲染听感检查（时长、峰值、结尾曲线）；
6. 按需调 `gain_db` / `reverb_mix` / 力度，反复 4~5 步直到满意；
7. 导出 MIDI，需要时进 DAW 精修。
